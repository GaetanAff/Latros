# Audits des sources candidates

Ce répertoire conserve les décisions de sélection prises avant toute ingestion. Un audit terminé
peut conclure à un `NO-GO` : cela signifie que la décision est documentée, pas que la source est
autorisée. Chaque audit doit être redaté si la version, la licence, le périmètre ou le producteur
change.
